GlobalProtect VPN Authentication Timeout on Remote Workstations

Severity: High Frequent / Known Problem Impact: Site / Remote Wide Account: Health Carousel Occurrence Count: 24 tickets Last Occurred: Oct 26, 2026

⚡ Quick Fix (Immediate Resolution)

Kill the cached PanGPS service and flush DNS resolution on the agent's PC: 

net stop PanGPS && ipconfig /flushdns && net start PanGPS
Troubleshooting Flowchart
Start: User reports VPN Connection Failed ➔ Decision: Can user ping 8.8.8.8? ➔ Action: Restart Gateway

Numbered Resolution Steps
  1. Verify workstation has active internet access by pinging default gateway.
  2. Open Windows Services (`services.msc`) and locate Palo Alto Networks GlobalProtect.
  3. Restart the service and confirm status transitions to Running.
  4. Have user re-enter MFA token code in the authenticator prompt.
